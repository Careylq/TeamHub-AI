# 前端面试高频考点（简答）

## JavaScript 事件循环

JS 是单线程，靠事件循环调度。宏任务（setTimeout、I/O）和微任务（Promise.then、queueMicrotask）交替执行：每轮先执行一个宏任务，再清空全部微任务，然后进入下一轮。经典输出题："Promise.resolve().then(() => console.log(1)); setTimeout(() => console.log(2), 0)" 输出 1、2。

## 闭包

函数 + 它定义时所在作用域的引用。用途：封装私有变量、防抖节流、柯里化。注意内存泄漏：闭包长期持有大对象时需手动释放。

## 防抖 vs 节流

防抖（debounce）：触发后延迟执行，期间再次触发重置计时——用于搜索输入。节流（throttle）：固定间隔内最多执行一次——用于滚动/resize。实现都要用闭包保存 timer。

## SSE vs WebSocket

SSE（Server-Sent Events）：基于 HTTP，服务端单向推送，EventSource 自动重连，只能 GET。WebSocket：全双工，双向通信，需握手。AI 流式对话场景用 SSE 足够（服务端→客户端单向流），且 fetch + ReadableStream 可带 POST/Authorization。

## 浏览器缓存

强缓存（Cache-Control max-age / Expires）直接走本地。协商缓存（Last-Modified / ETag）请求服务端判断 304。前端构建用 content hash 文件名实现"依赖不变则长期缓存"。

## React 性能优化

React.memo 浅比较 props 跳过重渲染（但 props 每次新引用时反而更慢）。useMemo 缓存计算结果，useCallback 稳定函数引用。虚拟列表只渲染可视区。注意：memo 配合不可变数据才有意义。

## 跨域 CORS

浏览器同源策略限制。解决：CORS 头（Access-Control-Allow-Origin）、代理（dev server proxy）、JSONP（仅 GET）。开发环境用 Vite 代理避免跨域。

## 虚拟列表原理

只渲染可视区 + 缓冲区行，用 paddingTop/paddingBottom 撑开滚动条。固定行高 O(1) 定位（scrollTop / rowHeight），动态行高需测量或预估。

## 前端权限安全边界

前端权限（菜单隐藏/按钮禁用）只是 UI 层优化，可被绕过（改 localStorage）。真正安全在后端鉴权（JWT 验证 → 查角色 → 比对接口权限）。
